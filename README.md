# Complete AIML Learning Workspace

This repository is a structured learning space for data science, machine learning, statistics, and data visualization. It contains beginner-friendly notebooks, practical projects, datasets, and study notes arranged by topic so you can learn step by step.

## What is inside this workspace?

- Core machine learning concepts and terminology
- Supervised learning topics such as regression and classification
- Advanced concepts like hyperparameter tuning, ensemble learning, and unsupervised learning
- Statistical testing notebooks
- Visualization notebooks using Matplotlib, Seaborn, and Cufflinks
- Real datasets for hands-on practice

## Recommended learning path

1. Start with the notebooks in [machine learning/machine learning part 1](machine%20learning/machine%20learning%20part%201)
2. Move to [machine learning/machine learning part 2](machine%20learning/machine%20learning%20part%202) for regression and model evaluation
3. Study [machine learning/machine learning part 3](machine%20learning/machine%20learning%20part%203) for classification algorithms
4. Continue with [machine learning/machine learning part 4](machine%20learning/machine%20learning%20part%204) for advanced ML concepts
5. Practice statistics and visualization notebooks to strengthen your understanding

1. Open the folder in VS Code.
2. Open any notebook you want to study.
3. Run the cells one by one to learn interactively.
4. Review the notes and images to strengthen your understanding.
